# 项目分析报告

## 概述

当前项目是一个 **代码阅读器 (Code Reader)** 应用，采用 monorepo 架构，目标是提供代码分析、依赖图生成、流程图可视化和笔记记录功能。

## 技术栈

| 类别 | 技术 |
|------|------|
| 包管理 | pnpm (v10.4.1) + workspace |
| 语言 | TypeScript |
| 前端框架 | React 18 |
| 构建工具 | Vite |
| 桌面应用 | Electron |
| 样式 | SCSS |
| 代码规范 | ESLint + Prettier |

## 项目结构

```
code-reader/
├── packages/
│   ├── cli/          # 命令行工具 (待开发)
│   ├── desktop/      # Electron 桌面应用 (主要代码)
│   ├── lib/          # 核心库 (待开发)
│   ├── ui/           # UI 组件库 (待开发)
│   └── web/          # Web 端 (待开发)
├── package.json
├── pnpm-workspace.yaml
└── tasks.md
```

## 各模块状态

### ✅ desktop (已实现基础功能)

**主进程 (main)**
- `index.ts` - Electron 主进程入口，窗口创建，IPC 通信
- `preload.ts` - 预加载脚本，暴露安全 API

**渲染进程 (render)**
- `App.tsx` - 主应用组件
- `components/Layout` - 布局组件（Header + Main）
- `components/FileTree` - 文件树组件（支持展开/折叠）
- `components/CodeViewer` - 代码查看器

**已实现功能：**
1. ✅ 打开本地文件夹
2. ✅ 显示目录树结构
3. ✅ 查看文件内容
4. ✅ 基础深色主题

### ⏳ ui (待开发)

## 现有代码问题

### 1. 样式问题 🎨
- UI 设计简陋，缺乏现代感
- 没有主题切换功能
- 组件样式不统一
- 缺少图标系统
- 没有动画过渡效果

### 2. 架构问题 🏗️
- 组件与样式耦合
- 没有状态管理
- 缺少错误边界
- IPC 通信没有类型安全

### 3. 功能缺失 ⚠️
- 没有代码高亮
- 没有搜索功能
- 没有笔记功能
- 没有依赖分析
- 没有 GitHub 集成
