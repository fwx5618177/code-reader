## 1. 五分钟上手

应用有三个模式，用顶部标签或 ⌘1 / ⌘2 / ⌘3 切换：

| 模式 | 用来做什么 | 典型操作 |
|------|-----------|----------|
| 知识库（⌘1） | 收集一切：想法、录音、截图、文件、网页链接。AI 自动转写、写摘要、打标签、找关联 | ⌘N 快速记录，⌘⇧R 录音 |
| 写作（⌘2） | 写长文：Markdown 笔记、LaTeX 论文、纯文本 | 左侧新建文档，像 Typora 一样直接写 |
| 阅读（⌘3） | 读收藏的网页、文档与笔记，高亮并摘录回知识库 | 选中文字 → 摘录到知识库 |

推荐的第一次体验：

1. 打开 **设置（⌘,）→ AI 服务**，添加一个服务商并填写 API Key（没有也能用，只是没有 AI 整理，见第 7 节）。
2. 按 **⌘N**，随手写一句话，⌘ + Enter 保存。右下角会出现“AI 正在整理”的任务浮窗，几秒后条目会出现摘要和标签。
3. 切到 **写作（⌘2）**，新建一个 Markdown 文档，输入 `# 标题`、`**粗体**`、`$E=mc^2$`，体会“输入即渲染”。
4. 在文档里输入 `[[`，选择另一篇笔记建立双向链接，然后看右侧的“反向链接”面板和“局部图谱”。

**界面布局**

- **标题栏左侧**是知识库选择器：可以建多个互相独立的知识库（如“工作”“个人”），在这里切换、新建、改名或删除，见第 10 节。
- **最左侧的竖排按钮（Ribbon）**切换侧栏显示的内容，每个模式各自记住上次打开的面板：

| 模式 | 侧栏面板 |
|------|----------|
| 知识库 | 文件夹、搜索、标签（标签云，点击按标签筛选）、录音（播放、重命名、删除）、知识图谱、日历（按天查看条目、写日记）、最近 |
| 写作 | 大纲（点击跳到标题）、文件、参考（反向链接与出链）、标签、最近 |
| 阅读 | 章节（目录与高亮）、书签、书库、搜索、最近阅读 |

## 2. 支持哪些文件，分别用来做什么

### 2.1 写作文档：三种格式

写作模式的文档按**文件名扩展名**决定格式。新建文档时在类型选择里挑选，之后改标题也会自动保留扩展名。

| 格式 | 扩展名 | 适合写什么 | 编辑方式 | 保存为 |
|------|--------|-----------|----------|--------|
| **Markdown** | `.md` `.markdown` `.mdown` `.mkd` | 日常笔记、博客、文档、读书笔记——**绝大多数情况选它** | 所见即所得：输入 Markdown 语法立即变成格式，光标靠近时显示原始标记 | 标准 Markdown 文本（GFM 表格、任务列表、`$` 公式、`[[ ]]` 链接） |
| **LaTeX** | `.tex` `.latex` `.ltx` | 学术论文、大量公式与交叉引用、需要投稿排版的文档 | 源码编辑 + 实时渲染预览（源码 / 渲染 / 分栏三种视图） | LaTeX 源码 |
| **纯文本** | `.txt` `.text` | 不需要任何格式的内容：日志、清单、草稿、要原样保存的文字 | 普通文本编辑，**不会**把 `#`、`*` 等符号当成格式 | 原样文本，一行就是一行 |

怎么选：

- 不确定就用 **Markdown**。它也能写公式，表格、代码、链接都支持，而且是通用格式，以后导出到任何地方都能用。
- 只有当你需要 LaTeX 的完整排版能力（`\section`、`\cite`、`\begin{theorem}` 等）时才用 **LaTeX**。
- 想完全避免格式化（比如粘贴命令行输出）用 **纯文本**。

> 旧版本的文档以 HTML 保存。打开时会自动识别并正常显示，下次保存时自动转换为 Markdown，不需要手动处理。

### 2.2 知识库条目：九种类型

知识库里的每一条记录叫“条目”，有九种类型。**你不需要手动选类型**，快速输入会按你提交的内容自动判断：

| 类型 | 是什么 | 怎么产生 | AI 会做什么 |
|------|--------|----------|-------------|
| 笔记 note | Markdown 文字笔记，同时也是写作模式里的文档 | 快速输入选“文字”；写作模式新建的 Markdown 文档；阅读时的摘录 | 摘要、要点、标签、语义索引、发现关联 |
| 音频 audio | 录音与音频文件 | 快速输入“语音”直接录音（⌘⇧R），或在“文件”中拖入音频 | **先转写成文字**，再摘要、打标签、建索引 |
| 图片 image | 截图、照片、图表 | 快速输入“图片”，拖拽或粘贴 | 保存原图；可加标签，参与语义索引 |
| 视频 video | 视频文件 | “文件”中拖入视频 | 保存原文件，应用内可播放 |
| 文档 document | PDF、EPUB、Word、表格、演示文稿等 | “文件”中拖入（任何模式下添加的 PDF / EPUB 附件都会归为文档） | 保存原文件；PDF / EPUB 会提取全文，可被搜索，并能在应用内阅读；自动加入阅读书架 |
| 网页 webpage | 保存了正文的网页剪藏 | 快速输入选“网址”并粘贴链接，自动剪藏正文 | 摘要、标签；自动加入阅读书架 |
| 代码 code | 代码片段 | 代码类内容 | 标签、语义索引 |
| 书签 bookmark | 稍后阅读的链接 | 网页剪藏失败时（如需要登录、网络错误、链接不是网页）自动保存为书签 | 可写备注；自动加入阅读书架 |
| 文件 file | 其他任意文件 | “文件”中拖入无法识别类型的文件 | 保存原文件 |

原则：**原始内容永远保留**（录音、原图、原文件都在附件目录里），AI 生成的摘要和标签只是方便查找的“索引”，不会替换原文。

## 3. Markdown 写作（Typora 式所见即所得）

Markdown 文档没有“编辑 / 预览”的割裂：你输入的语法会立刻变成格式。光标移进某段格式时，两侧会淡淡地显示它的原始标记（比如粗体两边的 `**`、标题前的 `##`），离开后标记隐藏，所见即最终效果。

### 3.1 输入什么得到什么

**块级（在行首输入）**

| 输入 | 得到 |
|------|------|
| `# ` 到 `###### ` | 一到六级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- ` 之后再输入 `[ ] ` 或 `[x] ` | 任务列表（点击复选框勾选） |
| `> ` | 引用 |
| `---` + 空格 | 分割线 |
| ` ```js ` + 回车（或空格） | 代码块（语言可改，点击代码块进入编辑） |
| `$$` + 回车 | 公式块（立即进入公式编辑） |
| `\| 列1 \| 列2 \|` + 回车 | 两列表格，光标进入第一个数据单元格 |

**行内（输完结束符号后立即生效）**

| 输入 | 得到 |
|------|------|
| `**文字**` 或 `__文字__` | **粗体** |
| `*文字*` 或 `_文字_` | *斜体* |
| `` `代码` `` | `行内代码` |
| `~~文字~~` | ~~删除线~~ |
| `[文字](https://网址)` | 链接 |
| `$公式$` | 行内公式（例如 `$x^2$`） |
| `$$公式$$`（单独成段） | 公式块 |
| `[[笔记标题]]` 或 `[[标题\|显示文字]]` | 双向链接（见第 8 节） |
| `[[笔记标题#小节]]` / `[[#小节]]` | 链接到某个标题 |
| `![[笔记标题]]`（单独成段） | 嵌入另一篇笔记、某个小节或图片 |

> 写金额不用担心：`$5 和 $10` 这类写法不会被当成公式（`$` 后紧跟空格、或结尾 `$` 后紧跟数字时不会触发）。

### 3.2 斜杠命令

在行首或空格后输入 `/`，弹出命令菜单，可继续输入文字过滤（支持中文和拼音首字母，比如 `/bg` 找“表格”），↑↓ 选择，回车执行：

标题 1–3、无序列表、有序列表、任务列表、引用、代码块、公式块、行内公式、表格、分割线、粗体、斜体、删除线。

### 3.3 表格

- 新建：输入 `| 列1 | 列2 |` 后回车，或斜杠命令“表格”。
- **Tab / Shift+Tab** 在单元格之间移动，在最后一个单元格按 Tab 自动添加新行。
- **⌘ + Enter / ⌘⇧ + Enter** 在当前行下方 / 上方插入一行；**⌘⇧ + Backspace** 删除当前行。
- **⌘⌥ + ← / →** 在当前列左侧 / 右侧插入一列；**⌘⌥ + Backspace** 删除当前列。
- 也可以点表格左侧的块手柄 ⋮⋮，在菜单的“表格”一栏里插入或删除行列（光标在表格内时作用于光标所在单元格，否则作用于最后一个单元格，菜单中会标出是第几行第几列）。
- 删除表头行时，下一行自动成为表头；删掉最后一行或最后一列会删除整张表格。
- 对齐方式保存在 Markdown 中（`:---` 左对齐、`:---:` 居中、`---:` 右对齐），增删列时其余列的对齐方式保持不变。

### 3.4 代码块与公式块

- 代码块平时显示语法高亮，**点击进入编辑**（CodeMirror，带代码补全）。在第一行按 ↑ 或最后一行按 ↓ 可以离开代码块。左上角下拉框切换语言。
- 公式**点击或用方向键移到上面即展开源码**，下方实时显示渲染结果。
  - 行内公式：Enter 完成；块级公式：⌘ + Enter 完成（Enter 用来换行）。
  - 在源码开头按 ← / ↑、结尾按 → / ↓ 会离开公式回到正文；Esc 也可退出。
  - 清空源码后退出，公式会被删除。

### 3.5 快捷键

| 快捷键 | 作用 |
|--------|------|
| ⌘B / ⌘I / ⌘E | 粗体 / 斜体 / 行内代码 |
| ⌘⇧X | 删除线 |
| Shift + Enter | 段内换行（不新起段落） |
| Tab / Shift+Tab | 列表缩进 / 取消缩进（表格中为切换单元格） |
| ⌥↑ / ⌥↓ | 把光标所在的块上移 / 下移 |
| ⌘↵ / ⌘⇧↵ / ⌘⇧⌫ | 表格：下方插入行 / 上方插入行 / 删除行 |
| ⌘⌥← / ⌘⌥→ / ⌘⌥⌫ | 表格：左侧插入列 / 右侧插入列 / 删除列 |
| ⌘Z / ⌘⇧Z | 撤销 / 重做 |
| ⌘F / ⌘H | 文内搜索 / 替换 |
| ⌘S | 立即保存（平时会自动保存） |
| ⌘⇧F | 专注模式（Esc 退出） |

### 3.6 大文档

几万字的长文也能流畅编辑，不需要拆分：

- 每次修改只重新保存被改动的段落（实测 1 万个段落、约 300KB 的文档，每次按键的保存开销约 0.8ms）。
- 文档超过 150 个段落时自动启用分块渲染：屏幕外的内容暂不排版，滚动到附近时再渲染。
- 代码块在滚动到附近时才做语法高亮。

### 3.7 标签页与分栏

从左侧文档列表、搜索或链接打开文档时，会在编辑器上方的标签栏中打开一个标签（已打开则直接切换过去），不会替换当前文档。

- 标签显示文档标题，有未保存修改时标题旁出现圆点；文档改名后标签标题自动更新。
- 点 **×** 或用鼠标**中键**点击标签即可关闭。关闭有未保存修改的标签前会先保存，保存失败时标签保留，修改不会丢失。
- **拖动标签**可调整顺序。
- 打开的标签在重启后自动恢复；已删除文档的标签会自动关闭。

**分栏**：点标签栏右侧的分栏按钮（或按 ⌘\\）把编辑区分成左右两栏，每栏有自己的标签组和编辑器。

- **两栏都可以直接编辑**。在哪一栏里点击（或用 Tab 把焦点移过去），哪一栏就是“聚焦栏”；切换聚焦栏不会重新加载文档，光标和滚动位置都保留。
- 从左侧打开的文档进入聚焦栏；把标签拖到另一栏的标签栏即可移过去。
- 两栏打开同一篇文档时，一栏的修改（正文和标题）会在片刻后同步到另一栏，适合一边看前文一边写后文。
- 反向链接面板、大纲、底部字数与保存状态、版本历史以及插件命令都作用于聚焦栏的文档。
- 再点一次分栏按钮（或 ⌘\\）关闭分栏，两栏的标签合并到一起。

| 快捷键 | 作用 |
|--------|------|
| ⌘W | 关闭当前标签 |
| ⌘⇧T | 重新打开最近关闭的标签（也可点标签栏的“重新打开”按钮） |
| ⌃Tab / ⌃⇧Tab | 切换到下一个 / 上一个标签 |
| ⌘\\ | 打开 / 关闭分栏 |

专注模式（⌘⇧F）下会隐藏标签栏和分栏，只显示当前文档。

### 3.8 版本历史与对比

点编辑器底部的时钟图标打开“版本历史”。手动保存会生成版本，编辑时也会自动保存版本（至少间隔 5 分钟）。展开某个版本后可以：

- **预览**：查看该版本的完整内容。
- **对比当前**：显示从该版本到当前编辑内容的差异。
- **对比上一版**：显示上一个版本到该版本的改动（列表最后一项需先点“加载更多”）。
- **恢复**：把文档恢复到该版本，恢复本身也会生成一个新版本，可以再恢复回来。

差异视图中红色为删除、绿色为新增，行内实际改动的文字会加深显示；可在“行内 / 分栏”之间切换，大段未变化的内容会折叠，点击展开。对比窗口里也可以直接恢复到该版本。

**自动清理（分层保留）**：版本越旧保留得越稀疏——最近 24 小时内的版本全部保留；30 天内每天保留当天最后一个；26 周内每周保留一个；更早的每月保留一个；每篇文档的最新版本始终保留。每次生成新版本后自动按这个策略清理该文档。每个版本都是完整快照，清理不影响剩余版本的预览和恢复。

在 **设置 → 版本保留** 中可以调整这三个时间段，查看全库版本数，并点 **立即清理** 按新策略清理所有文档。策略保存在当前知识库中，不同知识库可以各自设置。

### 3.9 块手柄与块菜单

把鼠标移到段落、标题、列表、引用、代码块、表格等任意一块内容上，左侧会出现手柄 **⋮⋮**：

- **拖动手柄**：把整块移动到其他位置（拖动时显示插入线）。拖动时按住 ⌥（Windows/Linux 为 Ctrl）则是复制。
- **点击手柄**：打开块菜单，可用 ↑↓ 选择、回车执行、Esc 关闭。
  - **转换为**：正文、一至三级标题、引用、代码块、无序 / 有序 / 任务列表。当前类型高亮显示；列表之间互转保留嵌套，转为代码块时公式、双向链接等保留为源码，代码块转为正文时每行一段。表格、公式块、分割线以及包含它们的引用 / 列表无法无损转换，对应项不可用。
  - **上移 / 下移**（⌥↑ / ⌥↓）、**复制块**、**删除块**。
  - 表格还会出现“表格”一栏：插入 / 删除行列（见 3.3）。

### 3.10 拼写检查

编辑器会用红色波浪线标出拼写错误的单词。拼写检查在后台线程进行，只检查屏幕上可见且改动过的内容，长文不会变卡。

- **检查范围**：拉丁字母、西里尔字母等拼音文字的单词。中日韩文字、代码块与行内代码、链接、公式、网址 / 邮箱 / 文件路径、带数字或下划线的词、全大写缩写（如 HTTP）和驼峰式命名（如 useState）不检查。
- **右键标红的单词**：选择建议替换；或选 **添加到词典**（永久保存在你的个人词典中，所有词典通用）；或选 **本次忽略**（只在本次运行期间不再标出该词，不会保存，重启后失效）。
- **设置**：设置 → 编辑器。可以开关拼写检查、切换词典（立即生效，无需重启）、导入或删除词典。内置词典为美式英语（en_US，来自 SCOWL）。
- **管理个人词典**：设置 → 编辑器 → **个人词典**，列出所有“添加到词典”的单词（按字母顺序，标题处显示总数），可在搜索框中筛选（不区分大小写）。点单词旁的 **删除** 即从个人词典中移除，立即生效：编辑器会重新检查，该词若不在当前词典中会重新标红，无需重启。

**导入其他语言的词典**

词典使用 Hunspell 格式（LibreOffice、Firefox 等软件使用的同一种格式），由一对同名文件组成：`xx_XX.aff`（词缀规则）和 `xx_XX.dic`（词表）。可以从这些地方获取：

- LibreOffice 扩展中心（extensions.libreoffice.org，搜索 “dictionary”）：下载的 `.oxt` 文件可以直接导入，其中的所有词典都会被导入。
- LibreOffice 词典仓库（github.com/LibreOffice/dictionaries）：每种语言一个目录，下载其中的 `.aff` 与 `.dic`。
- wooorm/dictionaries（github.com/wooorm/dictionaries）：整理好的 UTF-8 词典，每种语言目录下的 `index.aff` 与 `index.dic`。导入前建议把两个文件改名为语言代码（如 `de_DE.aff`、`de_DE.dic`），设置里就会显示为“德语（德国）”。

导入方法：设置 → 编辑器 → **导入词典**，选择 `.oxt`，或同时选择 `.aff` 和 `.dic`（只选其中一个时，会在同一目录下查找另一个）。导入后自动切换到新词典；重新导入同名词典会覆盖旧的。导入的词典保存在应用数据目录的 `spellcheck/dictionaries` 下，个人词典保存在同一目录下的 `spellcheck/user-words.txt`（每行一个词），建议在设置中管理；手动编辑该文件需重启后生效。

> 支持 Hunspell 常用的规则：前后缀（含条件、交叉组合、双重后缀）、各种标记格式（单字符 / 双字符 / 数字 / 别名）、常见字符编码，以及复合词规则（COMPOUNDFLAG / COMPOUNDBEGIN / COMPOUNDMIDDLE / COMPOUNDEND / ONLYINCOMPOUND / COMPOUNDMIN / COMPOUNDRULE），德语、荷兰语等语言的长复合词可以正确识别。

### 3.11 页面设置与打字机模式

点编辑器底栏的页面图标打开“页面设置”（写作模式与专注模式共用一份设置，修改即时生效，重启后保留）：

| 项目 | 可选值 |
|------|--------|
| 纸张背景 | 无 / 横线 / 方格 / 点阵，可调线条浓度。有背景时正文按整行排列，文字始终落在线格内 |
| 页宽 | 窄（560px）/ 中（720px）/ 宽（900px）/ 全宽 |
| 正文 | 无衬线 / 衬线字体，字号 12–24px，行距 1.4–2.4 倍 |
| 打字机模式 | 开启后光标所在行始终保持在编辑区垂直中央，文末留出半屏空白，写到最后几行也不用低头 |

“恢复默认”一键还原；Esc 或再点一次图标关闭浮层。

## 4. 数学公式

公式渲染器是自研的，不依赖 KaTeX / MathJax，在 Markdown 文档、LaTeX 文档、预览和阅读模式中效果一致。写法与 LaTeX 相同，下面是支持范围。

| 类别 | 支持的写法 |
|------|-----------|
| 基础 | 上下标 `x^2` `a_{ij}`、撇号 `f'`、分数 `\frac` `\dfrac` `\tfrac` `\cfrac`、中缀 `{a \over b}` `{n \choose k}`、根号 `\sqrt[n]{x}`、二项式 `\binom` |
| 符号 | 希腊字母（含 `\varepsilon` 等变体）、关系与否定（`\leq` `\neq` `\not\in`）、运算符、上百个箭头、集合与逻辑符号、`\R` `\N` `\Z` `\Q` `\C` 等简写 |
| 大型运算符 | `\sum` `\prod` `\int` `\iint` `\oint` `\bigcup` 等；块级公式中上下限在正上/正下方，行内在右侧（与 TeX 一致）；`\limits` `\nolimits` 可强制指定 |
| 函数 | `\sin` `\log` `\lim` `\max` `\det` 等，`\operatorname{argmax}`、`\operatorname*{argmax}`（带上下限）、`\bmod` `\pmod{n}` |
| 括号 | `\left( … \middle| … \right)` 自动伸缩，`\big` `\Big` `\bigg` `\Bigg` 固定尺寸，`\langle` `\lfloor` `\lceil` `\|` 等 |
| 字体 | `\mathbb` `\mathcal` `\mathscr` `\mathfrak` `\mathbf` `\mathrm` `\mathit` `\mathsf` `\mathtt` `\boldsymbol` `\bm`，以及旧式 `{\bf …}` |
| 文字 | `\text{…}`（可内嵌 `$…$`）、`\textbf` `\textit` `\texttt` `\mbox` |
| 装饰 | `\hat` `\bar` `\vec` `\tilde` `\dot` 等重音、`\widehat`、`\overline` `\underline`、`\overbrace{…}^{注释}` `\underbrace{…}_{注释}`、`\overset` `\underset` `\stackrel`、`\overrightarrow`、`\xrightarrow[下]{上}` |
| 强调 | `\boxed`、`\cancel` `\bcancel` `\xcancel`、`\color{red}` `\textcolor{blue}{…}` `\colorbox`、`\phantom` |
| 间距 | `\,` `\:` `\;` `\!` `\quad` `\qquad` `\hspace{1em}` `\kern` `\mkern18mu` |
| 环境 | `matrix` `pmatrix` `bmatrix` `Bmatrix` `vmatrix` `Vmatrix` `smallmatrix`、`array{c\|l}`（列格式、竖线、`\hline`）、`cases` `dcases` `rcases`、`aligned` `align` `alignat` `split` `gathered` `gather` `multline` `equation`、`\substack` |
| 编号 | `\tag{1.2}` `\tag*{…}`；`\label` `\nonumber` `\notag` 会被接受（不报错） |

写错时不会整个公式消失：未知命令以红色波浪线显示原文，鼠标悬停可看到原因。

## 5. LaTeX 文档与纯文本

### LaTeX（`.tex`）

- 左侧源码（语法高亮），右侧实时渲染，可切换“源码 / 渲染 / 分栏”。两侧滚动位置自动对齐。
- 支持章节、列表、文字格式、各类数学环境（与第 4 节相同的公式能力）。
- 大文件（几百 KB）采用增量解析与后台渲染，编辑不卡顿。
- 写作侧边栏的“加载 LaTeX 示例”可以快速体验。

### 纯文本（`.txt`）

- 一行就是一行，不做任何格式识别；输入 `# ` 不会变成标题。
- 适合保存原样文本。需要格式时，把扩展名改成 `.md` 即可切换为 Markdown。

## 6. 知识库：随手丢进来，AI 帮你整理

### 6.1 快速输入（⌘N）

任何模式下按 **⌘N** 打开快速输入，⌘⇧R 直接进入录音。五种输入方式：

| 方式 | 怎么用 | 生成的条目 |
|------|--------|-----------|
| 文字 | 直接打字，第一行自动作为标题 | 笔记（同时出现在写作模式的文档列表中） |
| 语音 | 点击开始录音，再点停止 | 音频（AI 自动转写） |
| 图片 | 拖拽或粘贴图片 | 图片 |
| 文件 | 拖拽任意文件 | 按文件类型识别为音频 / 视频 / 图片 / 文档 / 文件 |
| 网址 | 粘贴链接 | 书签 |

可选填写标题和标签（回车添加），**⌘ + Enter** 保存。保存后 AI 在后台处理，右下角浮窗显示每一步的进度（语音转写 → 生成摘要 → 提取标签 → 建立语义索引 → 发现关联），点击浮窗中的条目可直接打开。

**长文档（整本书、长录音转写）同样完整处理，不会截断**：

- **摘要**：较短的内容一次生成；超过约 8000 字时按段落分成若干部分，先逐段生成摘要，再汇总成全文摘要（各段摘要合起来仍然很长时会再归并一轮）。
- **标签**：长文逐段提取标签后合并，在全文多处出现的标签排在前面，最多保留 5 个。
- **语义索引**：全文按段落切成约 2000 字的片段逐段建立索引，语义搜索和“发现关联”以条目中最相近的片段计分，因此长文中只有某一章讲到的内容也能被搜到。
- 处理长文时浮窗会显示分段进度（如“分段摘要（3/12）”），需要的时间和 AI 调用次数随长度增加。旧版本建立的语义索引只覆盖了文档开头：在知识库「问答」视图的空白页点 **重建语义索引**，会一次性为所有“没有索引、索引后又修改过、或由旧版本建立”的条目重建覆盖全文的索引（已是最新的条目不会重复调用）；也可以在单个条目详情的「AI 解读」中点 **重新处理**。

**录音波形**：录音时计时下方会显示实时音量波形，最新的声音在最右侧；说话时柱子明显升高，如果始终是一条平线，说明麦克风没有收到声音（检查系统麦克风权限或输入设备）。停止录音或关闭窗口时波形随之停止。

### 6.2 浏览与查找

知识库主界面顶部可切换三个视图：**条目 / 图谱 / 问答**。

**条目视图**

- 左侧边栏是“文件夹”：
  - 智能文件夹：全部、最近（7 天内更新）、收藏、未标签，按规则自动计算，不需要手动维护。
  - 我的文件夹：点击 + 新建，用来手动归类。文件夹可以多层嵌套，点击文件夹前的箭头展开 / 折叠子文件夹，展开状态在重启后保持；每个文件夹旁显示直接放在其中的条目数。
- 搜索框会同时搜标题、正文、摘要、转写文字和标签；空格分隔多个词表示“同时包含”。
- 类型筛选（9 种类型，带数量）、标签筛选（可多选）、排序（最近更新 / 创建时间 / 标题）、分组（不分组 / 按日期 / 按类型 / 按标签），列表或卡片布局。
- ↑↓ 选择条目，Enter 或双击打开：笔记在写作模式中打开；PDF、EPUB 等文档和网页剪藏在阅读模式中打开。

**详情面板**（右侧，选中条目后显示）

- 可直接修改标题、增删标签，收藏、置顶、删除；通过“文件夹”下拉框把条目移到某个文件夹（选“未归档”即移出；子文件夹以“上级 / 子文件夹”的完整路径列出）。
- 笔记顶部有 **在写作中打开**；PDF、EPUB 等文档、网页剪藏以及其他带正文的条目顶部有 **在阅读模式中打开**，点击即切换到阅读模式并打开该条目（EPUB 按章节阅读）。
- **AI 解读**：摘要、要点、每个处理步骤的进度。点“重新处理”可让 AI 再整理一次。
- **原始内容**：笔记和网页渲染为正文；音频可播放并显示转写文字；图片、视频直接预览；文档可在文件夹中定位后用系统应用打开。
- **关联**：反向链接、出链、AI 计算的“语义相似”条目，以及以当前条目为中心的局部图谱。

**问答视图**

用自然语言向整个知识库提问，例如“我上周关于产品定价的想法有哪些？”。AI 会先检索相关条目，再据此回答；回答里的 `[1]` `[2]` 是来源编号，点击即可打开对应条目。可以连续追问，会结合前几轮对话。

回答生成过程中，发送按钮会变成 **停止**：点击后立即停止生成，已经生成的部分会保留并标注“已停止生成”，可点“重新生成”再问一次。被停止的不完整回答不会作为后续追问的上下文。

**整理文件夹与标签**

- **新建子文件夹**：右键某个文件夹（或点击其 ⋯ 按钮），选择“新建子文件夹”，会在其下新建并自动展开。
- **调整层级**：把文件夹拖到另一个文件夹上即可成为其子文件夹；拖到“我的文件夹”上则移到顶层。不能拖到自身或自己的子文件夹中，目标层级已有同名文件夹时也会提示失败。
- **重命名 / 删除文件夹**：在左侧“我的文件夹”中右键文件夹（或点击其 ⋯ 按钮），选择“重命名”或“删除”。同一层级不允许重名。删除文件夹不会删除其中的条目，它们会变为“未归档”，在“全部”中仍可找到；其中的子文件夹会上移一级（移到被删文件夹的上级下）；若正在查看被删除的文件夹，会自动回到“全部”。
- **移动条目**：在详情面板的“文件夹”下拉框中选择目标，或直接把条目从列表拖到左侧某个文件夹上（智能文件夹由规则自动计算，不接受拖入）。
- **管理标签**：点击条目视图工具栏的“管理标签”，可以看到所有标签及使用它的条目数：
  - 点击标签名即可重命名，Enter 保存、Esc 取消；如果新名称与已有标签相同，保存时两个标签会合并。
  - 勾选两个或以上标签，在底部选择保留哪一个后点“合并”，其余标签下的条目都会改用保留的标签，被合并的标签随之删除。
  - 点击标签前的色块选择颜色（或“无颜色”），颜色会显示在条目列表、标签筛选和标签编辑器中。
- **层级标签**（与 Obsidian 相同的写法）：用 `/` 分隔层级，如 `技术/前端/React`。
  - 给条目加 `技术/前端` 时，父标签 `技术` 不存在会自动创建（条目数为 0）。输入时多余的空格和开头的 `#` 会被去掉。
  - **按父标签筛选会包含所有子标签**：选 `技术` 会同时列出带 `技术/前端`、`技术/前端/React` 的条目；标签旁的数量也把子标签的条目算在内。`技术栈` 这种只是开头相同的标签不算子标签。
  - 侧栏 **标签** 面板在有层级标签时默认显示 **层级** 视图（可折叠，数字是含子标签的总条目数），也可切回 **云** 视图。旧数据里没有同名标签的父级显示为斜体分组，不能直接筛选。
  - “管理标签”中标签按层级缩进。重命名时填写完整路径即可改变层级（如把 `前端` 改为 `技术/前端`），**子标签会一并改名**（`前端/React` → `技术/前端/React`），对话框会提示影响的子标签数；不能把标签移到它自己的子标签下。
  - AI 打标签与自动归类会沿用已有的层级，把新标签放到合适的父标签下。

**AI 自动归类**（需要配置对话模型）

- **整个知识库**：点击工具栏的 **自动归类** 并确认。AI 会为每个条目建议文件夹（优先使用已有文件夹，必要时建议新建顶层文件夹）、补充规范化的标签（优先沿用已有标签的写法），并建议合并近似重复的标签（如 `react` / `React` / `ReactJS`）。条目很多或正文很长时会分批、分段分析后再汇总，不会截断内容。
- **单个条目**：在详情面板的“AI 解读”中点 **自动归类**，只为该条目生成文件夹与标签建议，不涉及其他标签的合并。
- **先审阅，再生效**：AI 只生成“建议”，不会直接改动知识库。分析完成后右下角浮窗留下一条记录并提供 **去审阅**；也可以随时点条目视图工具栏的 **待审阅归类**（按钮上的数字是待审阅的建议数）。在审阅面板中逐条 **接受**、**修改后接受**（改目标文件夹或增删要加的标签）或 **拒绝**，也可以全部接受 / 全部拒绝。标签合并建议排在前面。
- 归类只会**添加**标签，不会删除你已有的标签；已删除条目的建议不会出现在面板中。
- **定期整理建议**：在 **设置 → AI 服务 → 定期整理建议** 中开启并选择间隔（每天 / 每 3 天 / 每周 / 每两周 / 每月）。到期且上次整理后有新条目时，应用会在后台自动做一次整库自动归类，建议同样进入 **待审阅归类**；窗口不在前台时会发送系统通知。设置只对当前知识库生效；没有可用的 AI 服务时会等配置好后再整理。设置页会显示上次整理后新增的条目数与下次整理时间。

**日历与日记**

在侧栏切到 **日历**：月历上每天标出当天新建的条目数，有日记的日期另有标记。点击某天列出当天的条目；点 **写日记 / 打开日记** 会在写作模式中打开「日记 YYYY-MM-DD.md」，不存在时自动创建并打上「日记」标签。

### 6.3 全局搜索（⌘P）

在任意模式下同时搜索**写作文档**和**知识条目**（网页剪藏、录音转写、文档等），结果分两组显示，匹配的文字在摘要中高亮。配置了向量模型时，知识条目还会按语义匹配（意思相近但措辞不同也能找到）。

- 停止输入片刻后自动搜索；↑↓ 在两组结果间移动，Enter 打开，Esc 关闭。
- 写作文档在写作模式中打开；PDF、EPUB 等文档在阅读模式中打开；其他知识条目在知识库中打开并选中。
- 点搜索框右侧的筛选按钮可按类型筛选；清空搜索框会显示最近打开过结果的搜索词。

### 6.4 托盘菜单：最近打开

系统托盘（macOS 菜单栏）图标的菜单中有 **最近打开**，列出最近更新的 10 篇写作文档。点击即可唤起窗口并在写作模式中打开该文档；列表随文档保存自动更新。

## 7. 配置 AI 服务

知识库的自动整理与问答需要大模型服务。打开 **设置（⌘,）→ AI 服务**：

1. 点击“添加”，选择服务商（OpenAI、Anthropic、DeepSeek、Moonshot、智谱等），填写 API Key。
2. 三类模型分别对应三种能力，未填写的能力不会启用：

| 模型 | 用途 | 不填会怎样 |
|------|------|-----------|
| 对话模型 | 摘要、要点、标签、问答 | 没有 AI 整理和问答 |
| 向量模型（例如 `text-embedding-3-small`） | 语义索引、语义搜索、“相似条目”、图谱中的 AI 关联 | 搜索退化为关键词搜索，没有相似推荐 |
| 转写模型（例如 `whisper-1`） | 录音转文字 | 录音只保存原文件 |

3. 点“测试连接”确认可用；有多个服务商时，可分别指定“对话默认 / 向量默认 / 转写默认”。
4. **设置 → AI 服务 → 自动处理**：控制新内容是否自动生成摘要、自动打标签；**语音转写**页控制是否自动转写。

没有配置服务商时，所有内容照常保存，只是没有自动整理；知识库与问答界面会提示你去配置。API Key 只保存在本机。

**使用本地模型（Ollama）**：安装 [Ollama](https://ollama.com) 并拉取模型（如 `ollama pull qwen2.5:7b`、向量模型 `ollama pull nomic-embed-text`），在添加服务商时选择 Ollama，API Key 留空，对话模型填拉取的模型名。地址默认是 `http://localhost:11434/v1`（Ollama 的 OpenAI 兼容接口），旧版本保存的 `.../api` 地址会自动改正。Ollama 不提供转写接口。

## 8. 双向链接与知识图谱

### 8.1 建立链接

- 在 Markdown 文档中输入 `[[`，弹出所有文档标题，继续输入过滤，回车插入。
- 也可以直接写 `[[标题]]`；想显示不同的文字用 `[[标题|显示文字]]`。
- 链接到还不存在的标题完全没问题：点击这个链接会以该标题**新建文档**，这是“先写下想法，再补充内容”的常用方式。
- 标题匹配忽略大小写和扩展名：`[[读书笔记]]` 会链接到“读书笔记.md”。
- 代码块和行内代码里的 `[[…]]` 不算链接。

**链接到标题**

- `[[读书笔记#第二章]]` 指向“读书笔记”中的“第二章”标题，点击后打开该笔记并滚动到这个标题；也可以加显示文字：`[[读书笔记#第二章|第二章]]`。
- `[[#小结]]` 指向当前文档自己的标题，点击在文内跳转。
- 输入 `[[读书笔记#` 后，补全菜单会列出该笔记的所有标题（`[[#` 列出当前文档的标题），继续输入可过滤。
- 标题匹配同样忽略大小写与多余空格；带标题的链接在反向链接和图谱中计入目标笔记。

**链接到某一块（块级引用）**

比标题更细的粒度：可以链接到某一段、某个列表项、一张表格或一个代码块（写法与 Obsidian 相同）。

- 给块加上 ID：在段落或标题末尾写 ` ^块ID`（ID 由字母、数字和 `-` 组成，如 `这是结论 ^key-point`）；表格、代码块等在其后另起一段单独写 `^块ID`。ID 标记会以淡色显示。
- 链接：`[[读书笔记#^key-point]]`，点击后打开笔记、滚动到该块并短暂高亮；`[[#^key-point]]` 指向当前文档。嵌入写作 `![[读书笔记#^key-point]]`，只显示这一块。
- **不用手写 ID**：输入 `[[读书笔记#^`，补全菜单列出该笔记的所有块（段落、标题、列表项、表格、代码块），继续输入可按内容过滤。选中一个还没有 ID 的块时，会自动为它生成 ID 并写入目标笔记（只插入这一个标记，其余内容原样保留）。
- 在阅读模式中点击指向标题或块的链接，如果目标也能在阅读视图中打开，会留在阅读模式并定位过去；否则在写作模式中打开。

**嵌入**

- 在单独一段中写 `![[读书笔记]]`，会把整篇笔记的内容直接显示在当前位置；`![[读书笔记#第二章]]` 只嵌入这一节（到下一个同级或更高级标题为止）。
- `![[图片名.png]]` 嵌入知识库中的图片。
- 也可以在空段落输入 `![[` 后从补全菜单选择。
- 嵌入内容是只读的，始终显示被引用笔记的最新内容；点击嵌入左上角的标题打开原文，点击正文选中整个嵌入（可按退格键删除）。预览、阅读模式和知识库详情面板中同样展开。
- 嵌入可以嵌套，最多 4 层；两篇笔记互相嵌入时，在形成循环的位置停止展开并给出提示。
- 写在句子中间的 `![[…]]` 只是普通链接。

**重命名时自动更新链接**

- 在写作侧边栏重命名、修改编辑器顶部的标题（离开标题输入框时生效）、或在知识库详情面板中改标题后，其他笔记中指向原标题的 `[[原标题]]`、`[[原标题|显示文字]]`、`[[原标题#小节]]`、`![[原标题]]` 会自动改为新标题，显示文字和小节保持不变；完成后底部提示“已更新 N 篇笔记中的 M 处链接”。
- 只改链接本身，笔记的其他内容和格式原样保留；代码块、行内代码和公式中的 `[[…]]` 不会被改动。
- 新标题含有 `#` `|` `[` `]` 时无法作为链接目标，此时链接不会被改写，并会提示有多少处链接未更新。

### 8.2 反向链接面板

写作时右侧的面板（底栏的链接图标可开关，图标旁的数字是反向链接数）有四个页签：

| 页签 | 内容 |
|------|------|
| 反向链接 | 哪些笔记链接到了当前文档，并显示链接所在的那段话 |
| 出链 | 当前文档链接了哪些笔记；还未创建的目标显示“未创建 · 点击新建” |
| 未链接提及 | 正文提到了当前标题、但还没有加 `[[ ]]` 的笔记，方便补链接 |
| 局部图谱 | 以当前文档为中心的关系网 |

### 8.3 知识图谱

知识库顶部切到“图谱”查看整个知识库的关系网（全局），也可以切到“局部”只看选中条目周围 1–3 层。

- 节点大小表示连接数，颜色表示类型（左下角有图例）；实线是 `[[双向链接]]`，虚线是 AI 发现的语义关联（需要配置向量模型）。
- 拖动空白处平移，滚轮缩放，拖动节点调整位置；悬停高亮邻居，点击打开条目；点击灰色的“未创建”节点会新建对应文档。
- 工具栏可以搜索节点（Enter 定位），开关“孤立节点 / 未创建的链接 / AI 关联”。

**实体图谱**：工具栏的 **笔记链接 / 实体** 切换图层。实体图层展示 AI 从条目中抽取的人物、组织、地点、概念、事件、作品、技术等实体（统一颜色的节点），每个实体与提到它的条目相连，于是谈到同一个人或同一个概念的条目会通过实体聚在一起。

- 抽取实体：在实体图层点 **提取全部实体**（只处理新增或修改过、且有正文 / 转写 / 摘要的条目），或在条目详情的“AI 解读”中点 **提取实体**。长文会分段抽取后合并，同名实体（忽略大小写、全半角和书名号等）只保留一个。
- 点击实体节点，右侧列出提到它的所有条目（按提及次数排序），点击条目即可打开；点击条目节点直接打开条目。
- 勾选“只显示关联多个条目的实体”可以只看把不同条目连接起来的实体；“局部”模式下查看选中条目的实体及其相关条目。
- **实体关系**：抽取实体时 AI 还会识别正文中实体之间的关系（属于、成员、创建、位于、使用、影响、相关），在实体图层中连成实体之间的边。点击实体后侧栏以「实体 关系 实体」列出它的关系，附带原文证据和来源条目；条目详情的“关联”中也能看到与它提及的实体有关的关系。重新提取时该条目抽出的关系整体更新。

## 9. 阅读模式

### 书架

左侧是书架。**网页、书签、文档会自动上架**；其他条目（例如一篇长笔记）可以在阅读视图中点“加入书架”。书架按“全部 / 阅读中 / 未开始 / 已读完”筛选，按最近阅读排序。

### 阅读

- 右上角 **排版**：衬线 / 无衬线、字号、行宽、行高，设置会被记住。
- **目录**：自动生成，阅读时高亮当前章节，点击跳转。没有目录时侧栏只显示“高亮”页签。
- **进度**：自动保存，下次打开回到上次的位置；读到结尾自动标记已读，也可以手动标记。
- **书签**：点顶部的书签按钮记下当前阅读位置；在侧栏“书签”中点击跳回、可删除。侧栏“章节”显示目录与高亮。
- 有 AI 摘要的条目在正文前显示“AI 导读”。

### 高亮与摘录

选中正文中的文字，会出现两个按钮：

- **高亮**：标记这段文字，之后在“高亮”页签中可以查看和跳转。选区可以跨越加粗、链接、行内代码甚至多个段落。
- **摘录到知识库**：可加上自己的想法和标签，生成一条新的笔记。笔记中包含引用原文和 `[[来源]]` 链接，所以在来源文档的反向链接里能看到所有摘录。

### 网页剪藏

在快速输入（⌘N）中选“网址”并粘贴链接——在空的文字输入框里直接粘贴一个网址也会自动切换到“网址”。保存时应用会抓取网页、提取正文（去掉导航、广告等），转换成 Markdown 保存为“网页”条目，标题、来源链接和摘要一并保留，可以全文搜索、在阅读模式中高亮摘录。

- 只支持 http / https 链接，省略协议时按 https 处理。
- 网页需要登录、网络超时（20 秒）、页面超过 15 MB、链接不是网页（如直接指向 PDF）或识别不出正文时，会改为保存书签，并提示失败原因。
- **正文图片保存到本地**：剪藏时会下载正文段落中的图片，每张保存为一个“图片”条目（与剪藏在同一文件夹，标题形如“文章标题-图1-….jpg”，文件在附件目录中），正文中改为 `![[图片条目|替代文字]]` 嵌入——离线也能在阅读模式、知识库详情面板和写作编辑器中显示。每张图片最大 10 MB，超过时不保存（不会只存一部分）。
- 下载失败的图片（如防盗链、超时、链接不是图片、超过大小上限）保留原网页上的地址，并在保存后的提示中显示失败张数；这些图片阅读时仍需联网显示。标题和表格中的图片无法改为嵌入，同样保留原地址。
- 删除剪藏不会自动删除它的图片条目，需要时可在知识库中手动删除。

### PDF 与 EPUB

通过快速输入的“文件”或“附件”添加 PDF / EPUB，会保存为“文档”条目并自动上架：

- **全文可搜**：导入时提取所有页面 / 章节的文字，用于搜索和 AI 整理；原文件原样保存。扫描版 PDF 没有文字层，导入时会提示，可在阅读模式中识别后再检索（见下方“扫描版 PDF 文字识别”）。EPUB 会自动使用书中的书名作为标题。
- **PDF 阅读**：在阅读模式或知识库详情面板中直接翻阅。顶部工具栏可缩小 / 放大 / 适合宽度，并显示当前页码；页面滚动到附近时才渲染，再大的文件也能流畅滚动。文字可以选中复制。
- **EPUB 阅读**：在阅读模式（⌘3）的书架中打开，或在知识库详情面板中点 **在阅读模式中打开**，按章节显示，排版跟随“排版”设置。右侧“目录”来自书本自带的目录，点击即可跳转；正文末尾有“上一章 / 下一章”，书内的脚注与交叉链接也能直接跳转。阅读进度按整本书计算，下次打开回到上次的章节和位置。EPUB 中的脚本、样式与嵌入内容会被移除，只保留文字、图片、表格等正文内容。
- **PDF 目录**：PDF 自带书签（目录）时，阅读模式右侧“目录”按层级显示，滚动时高亮当前页所属的章节，点击跳到对应页。没有书签的 PDF 只显示“高亮”页签；只指向外部网址的书签项不会列出。
- EPUB 可以像网页一样高亮和摘录（高亮在当前章节中定位）。
- **PDF 高亮与摘录**：在阅读模式中选中 PDF 页面上的文字，同样会出现“高亮 / 摘录到知识库”。选区可以**跨页**：高亮按页记住各段文字，每一页滚动到附近、渲染出来时自动标出本页那一段；“高亮”页签中每条显示“第 N 页”或“第 N–M 页”，点击跳到起始页并定位。点击页面上已有的高亮可以整条删除。摘录生成的笔记在来源后注明页码（如“来源：[[论文.pdf]] · 第 12 页”）。知识库详情面板中的 PDF 只供预览，不显示高亮。
- **扫描版 PDF 文字识别**：打开 PDF 时会自动检测哪些页是没有文字层的扫描页，有扫描页时工具栏出现 **识别扫描页**。识别完全在本机进行（不上传任何内容），逐页显示进度，可以随时取消。识别完的页面可以像普通 PDF 一样选中、高亮和摘录；识别出的文字会写回条目，之后全局搜索也能搜到。结果保存在当前知识库中，再次打开不用重新识别（可点 **重新识别** 覆盖）；删除条目时一并删除。
  - **识别语言**：阅读 PDF 时在右上角 **排版** 中选择参与识别的语言。内置英文（eng）与简体中文（chi_sim）；其他语言可以点 **导入** 添加 Tesseract 语言数据文件（`.traineddata` 或 `.traineddata.gz`，可从 github.com/tesseract-ocr/tessdata 下载，文件名即语言代码，如 `jpn.traineddata`），导入的语言可以删除。同时勾选多种语言会变慢，建议只选文档实际使用的语言。

## 10. 数据存在哪里

所有数据都保存在本机。数据分为两类：属于某个**知识库**的，和整个应用共用的。

**多个知识库**

每个知识库有自己独立的数据库、附件和备份目录，彼此完全隔离（文档、条目、标签、文件夹、链接、版本、AI 结果都不互通），适合把工作与个人资料分开。

- **切换**：点标题栏左侧的知识库名称，在下拉中选择。切换前会先保存所有正在编辑的内容，然后重新加载窗口。
- **新建 / 改名 / 换颜色 / 删除**：在同一下拉中，或 **设置 → 知识库**。设置页还显示当前知识库的数据库与附件目录的完整路径，可在访达 / 文件管理器中打开。
- **删除**会弹出确认，确认后连同该知识库的数据库、附件与备份一起删除，无法恢复。默认知识库和当前打开的知识库不能删除（先切换到别的知识库）。

下表中的路径都相对于应用数据目录（macOS 为 `~/Library/Application Support/<应用名>`）。**默认知识库**沿用升级前的位置，即应用数据目录本身；之后新建的知识库位于 `workspaces/<知识库 ID>/`。

| 内容 | 位置（相对于知识库目录） |
|------|------|
| 文档、知识条目、标签、文件夹、链接、版本、实体与关系、待审阅归类、AI 任务 | `data/knowledge.db`（SQLite 数据库） |
| 录音、图片、文件等原始附件 | `attachments/` |
| 扫描版 PDF 的文字识别结果 | `ocr-results/<条目 ID>/` |
| 备份 | `backups/` |

| 应用共用的内容 | 位置（相对于应用数据目录） |
|------|------|
| 知识库列表 | `config/workspaces.json` |
| 应用设置 | `settings.json` |
| AI 服务商配置 | `config/ai-config.json`（只在本机） |
| 导入的拼写词典、个人词典 | `spellcheck/dictionaries/`、`spellcheck/user-words.txt` |
| 导入的文字识别语言数据 | `ocr/languages/` |
| 用户安装的插件 | `plugins/<插件 ID>/` |

写作的页面设置、标签页与分栏布局、插件的启用状态与插件自己保存的数据记在应用内部存储中。

升级说明：

- 早期版本把知识条目保存在 `knowledge-db.json`。升级后首次启动会**自动迁移到数据库**，原文件改名为 `knowledge-db.legacy.json` 保留备份。
- 早期版本的 AI 设置保存在 `ai-config.json`，同样会自动迁移，原文件改名为 `ai-config.legacy.json`。
- 早期以 HTML 保存的文档在下次保存时自动转为 Markdown。
- 引入多知识库之前的数据就是“默认知识库”，位置不变，不需要迁移。

## 12. 常见问题

**输入的 `**` 没有变成粗体？**
结束的 `**` 前不能是空格（`**文字 **` 不会生效），这与 Markdown 规范一致。也可以选中文字后按 ⌘B。

**想输入字面的 `$`、`*`、`[[`？**
在前面加反斜杠：`\$`、`\*`、`\[\[`。保存时编辑器也会自动转义正文中的这些符号。

**条目一直显示“AI 处理中”或报错？**
打开 设置 → AI 服务，点“测试连接”。常见原因是 API Key 失效、余额不足，或没有配置对应的模型（例如没有转写模型时录音无法转写）。失败的任务会自动重试几次，修好配置后可在详情面板点“重新处理”。

**语义搜索 / 相似条目 / 图谱虚线没有内容？**
需要配置向量模型，并让条目完成一次“建立语义索引”。配好向量模型后，可在「问答」视图点 **重建语义索引** 为已有条目批量补建。

**如何把一条知识库笔记拿去写长文？**
在详情面板点“在写作中打开”。知识库中的笔记和写作模式的文档是同一份数据，两边的修改互相可见。

**切换知识库后找不到之前的内容？**
每个知识库的数据是完全隔离的。点标题栏左侧的知识库名称切回原来的知识库即可；升级前的数据都在“默认知识库”中。

## 13. 插件

插件可以为编辑器增加命令、在状态栏显示信息。每个插件运行在独立的后台线程里，不能访问网络、文件和你的知识库，只能在你授权的范围内操作**当前文档**。

### 13.1 使用插件

- **管理**：设置 → **插件**。列出已安装的插件（名称、版本、说明、需要的权限、提供的命令与状态），可以启用 / 停用、重新加载、卸载。
- **授权**：首次启用时会弹窗列出插件要的权限，同意后才会运行；插件升级后新增了权限会再次询问。

| 权限 | 允许插件做什么 |
|------|----------------|
| `editor:read` | 读取当前文档的内容、选中文本与光标位置 |
| `editor:write` | 修改当前文档（插入、替换文本，移动光标） |
| `ui:message` | 显示提示消息 |
| `ui:dialog` | 弹出输入框、选择列表与确认框 |
| `ui:statusbar` | 在状态栏显示一项信息 |
| `storage` | 在本机保存插件自己的数据 |

- **执行命令**：按 **⌘⇧P**（Windows / Linux 为 Ctrl+Shift+P）打开命令面板，输入过滤后回车执行。命令作用于聚焦栏的文档；状态栏上的插件信息也可以点击执行对应命令。
- **内置示例「写作助手」**：插入当前日期、统计字数与预计阅读时间、设置字数目标并在状态栏显示进度。
- **安装其他插件**：在插件设置中点 **打开插件目录**，把插件文件夹放进去，再回到设置中启用。与内置插件同 ID 的用户插件会覆盖内置插件。只安装你信任来源的插件，并留意它申请的权限。

### 13.2 编写插件

一个插件就是插件目录下的一个文件夹，**文件夹名即插件 ID**，内含两个文件：

```
plugins/
└── my-plugin/
    ├── manifest.json
    └── main.js
```

`manifest.json`（`id` 必须与文件夹名一致，`version` 为 `x.y.z` 形式；`main` 省略时为 `main.js`）：

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "description": "在光标处插入分隔线",
  "main": "main.js",
  "permissions": ["editor:write", "ui:message"],
  "contributes": {
    "commands": [{ "id": "insert-rule", "title": "我的插件：插入分隔线" }]
  }
}
```

`main.js` 是一个单文件 ES 模块（不能再引用其他文件），导出 `activate`，可选导出 `deactivate`：

```js
export async function activate(app) {
  await app.commands.register('insert-rule', async () => {
    await app.editor.insertText('\n---\n');
    await app.ui.showMessage('已插入分隔线');
  });
}

export function deactivate() {}
```

`app` 上的全部方法都返回 Promise，调用没有申请的权限会报错：

| API | 说明 |
|-----|------|
| `app.commands.register(id, handler)` | 注册 manifest 中声明过的命令 |
| `app.editor.getContent()` / `setContent(text)` | 读取 / 替换当前文档全文（Markdown 或纯文本） |
| `app.editor.getSelection()` / `replaceSelection(text)` / `insertText(text)` | 选中文本、替换选区、在光标处插入 |
| `app.editor.getCursorPosition()` / `setCursorPosition(line, column)` | 光标位置（行按顶层块计数） |
| `app.editor.onDidChange(listener)` | 当前文档内容变化或切换到另一栏 / 另一篇文档时回调 |
| `app.ui.showMessage(text, type?)` | 提示消息，`type` 为 `info` / `warning` / `error` |
| `app.ui.showInput({ prompt, placeholder, value })` | 输入框，取消时为 `undefined` |
| `app.ui.showQuickPick(items, { placeholder })` / `showConfirm(text)` | 选择列表 / 确认框 |
| `app.statusBar.set({ text, tooltip, command })` / `clear()` | 状态栏项（每个插件一项），`command` 为点击时执行的本插件命令 |
| `app.storage.get / set / delete / keys` | 插件私有的键值存储（值需可序列化为 JSON） |

限制：`manifest.json` 不超过 64 KB，入口文件不超过 1 MB；插件中没有 `fetch`、DOM 与 Node.js 能力。修改代码后在插件设置中点 **重新加载**。内置的「写作助手」（应用安装目录的 `assets/plugins/writing-tools`）是一个完整的参考实现。
